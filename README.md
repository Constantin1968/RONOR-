# RONOR — Sovereign Generative Intelligence Runtime

> *"The world's first sovereignty-aware, evidence-governed AI runtime"*

**Category:** Developer Tools

RONOR is a Sovereign Generative Intelligence Runtime designed to bring transparency, economic optimisation, and verifiable evidence to enterprise AI workflows. It is built natively on **GPT-5.6** and operates across 7 operational planes.

---

## 🏗 Architecture: The 7 Operational Planes

RONOR breaks down AI inference into a governed, 7-plane pipeline. Every request passes through these planes, ensuring quality, security, and optimal resource usage.

1. **R-Gateway:** Ingress, API key auth, rate limiting, and prompt injection screening.
2. **R-Context:** Context management, semantic compression (when thresholds are exceeded), and session state persistence.
3. **R-Model Fabric:** The core routing engine powered by **GPT-5.6**. It dynamically selects the best model from 9 active models based on the EMS formula.
4. **R-Agent Runtime:** Multi-agent orchestration. Determines if an agentic loop is required and manages tool-use coordination.
5. **R-Execution:** Safe, sandboxed execution of tool calls and code generated by the Agent Runtime.
6. **R-Assurance:** Quality verification, hallucination risk assessment, sovereignty compliance checking, and immutable evidence chain construction.
7. **R-Economics:** Computes the final EMS score and tracks cumulative cost and token usage for continuous self-optimisation.

---

## 🧮 The EMS Formula

RONOR introduces the **Efficiency-Merit Score (EMS)**, a deterministic formula used by the Model Fabric to route requests and evaluate performance:

**EMS = Quality − Cost − Latency − Risk + Sovereignty + Evidence**

This ensures that every AI decision is not just accurate, but economically viable, compliant with data residency requirements, and backed by verifiable evidence.

## 🚀 Setup & Installation

### Prerequisites
- Node.js >= 20.0.0
- TypeScript >= 5.5.3

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Configuration
Copy the example environment file and add your OpenAI API key:
```bash
cp .env.example .env
```
Ensure `OPENAI_API_KEY` is set. The primary model is configured to `gpt-4o` by default, but the fabric routes intelligently.

### 3. Build & Run
```bash
npm run build
npm start
```
For development with hot-reloading:
```bash
npm run dev
```

### 4. Testing
RONOR includes a comprehensive suite of 27 end-to-end tests covering all 7 planes and the EMS formula.
```bash
npm test
```
